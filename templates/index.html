Safety Notice

This is an experimental demo. Directions are based on image position. Visual size is not actual distance measurement. Motion detection may be incorrect if the camera moves. It does not reliably detect walls or all obstacles. Do not use this system for real-world navigation or as a replacement for a cane, guide dog, or human assistance. Test only while stationary in a safe place.
